# Finup Web UI Prototype

UI-only web prototype for **Finup — Level up your finances.**

## Included
- Home / Overview / EMIs / AutoPay / Dues / Expenses
- Cards and card intelligence
- Pay module
- QR Scan & Pay simulation
- Eligible UPI / Card / Bank selection
- Payment review + Financial Firewall visual
- AI command center
- Activity & Audit
- Profile / Settings / Permission Center

## Not connected yet
Real authentication, bank/card/UPI APIs, payments, backend, database, production AI, and production security.

## Run
Requires Node.js LTS.

```bash
npm install
npm run dev
```

Open the Vite URL, normally `http://localhost:5173`.

Build:
```bash
npm run build
```
